# Shayan Ali — Developer Portfolio

Personal developer portfolio built with semantic HTML5, modern CSS3, and vanilla JavaScript.

## Live Demo & Repository
- **Live Site:** https://soomroshayan.github.io/shayan-portfolio/
- **Source Code:** https://github.com/soomroshayan/shayan-portfolio

## Features
- Responsive layout for desktop, tablet, and mobile devices
- Dark / Light theme toggle with `localStorage` persistence
- Mobile hamburger navigation menu
- Interactive project detail modals
- Featured projects showcasing PHP and MySQL eCommerce applications:
  - **Fast Food Website eCommerce** (`PHP`, `MySQL`) — https://shayanstores.ct.ws/index.php
  - **Stylish Online Store eCommerce** (`OOP PHP`, `MySQL`) — https://shayanstoreee.ct.ws/

## Local Setup
1. Clone or download the repository.
2. Place a profile image named `profile.jpg` in the root folder.
3. Open `index.html` in any web browser.
